# Worker 0.2.41：飞书提问卡片的跳过按钮

训练员要求在飞书提问卡增加跳过按钮。

## 行为

- 当前训练员提问卡增加独立的“跳过”回调按钮；自由文本提问也可跳过。
- 多题时保留最新已选答案，只将未答题标记为未提供答案。
- 用户跳过是明确的未作答行为，不伪造选项，也不代替权限审批。
- 原生异步提问继续用原问题ID同步，客户端能据此结束原提问窗口；
  飞书原卡片标为已跳过，部分跳过时标为已完成·部分跳过。
- 回调先持久化再ACK；重复点击不重复投递。
  排队中的跳过只有拿到原生接收回执才完成。
- 原有账号、聊天、消息ID、nonce、绑定epoch和source-turn检查保留；
  给溪流的提问不显示训练员跳过按钮。
- 不增加JSON输入卡，源题卡布局版本升级至4，旧卡片只更新原消息。
